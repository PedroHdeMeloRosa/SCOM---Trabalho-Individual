# SCOM - War Thunder Wiki (Sistema de Controle Operacional Militar)

Aplicação Web Full-Stack desenvolvida com arquitetura em três camadas (Controller, Service, Data Access Layer), autenticação baseada em sessão, proteção contra vulnerabilidades OWASP Top 10 e observabilidade básica.

---

## 1. Pré-Requisitos do Ambiente

* **Servidor Web:** Apache (XAMPP, WampServer ou equivalente)
* **Interpretador:** PHP 8.1 ou superior (com extensões `pdo_mysql`, `filter`, `mbstring`, `openssl`)
* **Banco de Dados:** MySQL 5.7+ ou MariaDB 10.4+
